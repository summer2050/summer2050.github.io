我的收获

以课题研究的目的去输出。即为了输出而去输入。

播客链接： https://www.xiaoyuzhoufm.com/episode/669202f08fcadceb90fd85d3

如何开始输出，写作？

直接开始。先找个公开的地方去说去写，拿到第一波用户的反馈。

既然花了那么长时间听播客，为什么不再多花几分钟把自己的思考写下来。

一、不知道输出什么

原因一：对生活太钝，不够敏感，觉得每天的生活都是重复的。

解决方法：善于观察，做一个有心人，把周围的一切当做选题库。

原因二：输入的质量和数量支撑不了输出。

脑子吃好东西才能产出好东西。

解决方法：

读书，定时定量读书。作者成立读书会读经典书目，每月1-2本，已经读了80多本。

没时间看书，听书也可以。

原因三：做到了输入，但没有把输入输出形成闭环，形成习惯。

建立输入到输出的通路：去写或对别人说所输入的内容。真正的明白是能够说得明白，写得明白，否则就是没有真正明白。

把输入到输出变成习惯：每日输出一定文字。

原因四：没有一个具体的问题要解决。

可以为输出而输入，为写而读。把问题当做一个个课题去研究。

二、不知道怎么写

  1. 心态上：允许自己笨拙。
  2. 脑子里有什么，先写下来，哪怕前言不搭后语，不是完整的句子。
  3. 碎片化输出。比如在即刻上分享生活，做一个有血有肉的人。
  4. 模仿某个人的写作风格。

三、写出来没有正反馈，没有动力写下去

写对别人有用的东西。

四、输出有心理负担

  1. 太宝贵自己的羽毛。

    把输出当成一种对话，而不是展现自己。

  2. 我是个i人，对外输出很恐惧。

    不能菜！可以摸鱼，可以翘班。

  3. 太追求完美。

    可以追求完美，得给自己一个明确的边界。

    比如时间截点，到约定的时间交出去。

  4. 坚持输出的必要条件——要有表达欲和分享欲，就是分享的热情。
