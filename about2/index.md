# About


### 第二博客是什么

有第二博客，必然有第一博客。

很多时候，人们建立博客，精心挑选精美的主题，乐此不疲地装修主题，但在输出内容上，则更新地很少。

为什么更新少？可能是没有想好以怎样的频率，写出怎样的内容。还可能是，对内容的要求过高，觉得写出来的东西不值得别人花时间阅读。

所以，我建立第二博客来应对完美主义的难题。第二博客的初衷是练习写作，保持更新，希望在实际写作中提高写作能力。之后挑选写的不错的、个人满意的文章放到第一博客中。

### 为什么要公开写作

因为希望写的东西能对他人有用吧。

我哼哧哼哧读了那么多东西，只读不记笔记，很快忘记。

记的笔记只给自己看，觉得有点可惜。

如果能把看到的东西分享给有缘人，万一对他人有用，那我的阅读和记录不算白费。

分享能让我的阅读和记录最大化功用。
