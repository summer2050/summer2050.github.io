【播客笔记】究竟什么是沟通能力？怎么评估自己沟通能力强不强？

2025-09-09 2 min read # 沟通 # learning # 播客

播客链接：https://www.xiaoyuzhoufm.com/episode/642a096eee9d8ca6ea2fc082

听后感受：收获一般。感觉没有特别干的货，也没有学到如何提高沟通力的具体方法。除了结构化表达这个通常建议

沟通才干靠前，有个核心特征，表达欲比较强。

我理解的沟通。它更像是一种动力，就是我有想去表达、去传播的一个动力。

沟通力的第一点：沟通力非常重要的一个点是，别人愿意跟你沟通。让人看见就愿意，去跟他聊。

沟通力强的人，沟通意愿应该强，但是不代表沟通意愿强，沟通力一定强。

表达力——是不是能够清晰简洁明快的，把你的观点，以及比如说你要表达的一些背景信息，说清楚？

如何提升表达的效率？

第一个：拎出主线和关键控制点。所有事情的阐述都尽可能控制在三分钟之内表达清楚。如果实在不行，就用后续再加信息的方式。信息量不是越充分越好，拎主线抓重点。

第二点：结构化表达。结构化表达最核心的点，是能节约时间，节约效率。
