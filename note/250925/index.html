推荐指数：四颗星

这本书主要讲人们做决策时常常出现的四个决策陷阱，针对这些决策陷阱，给出解决方式——WRAP决策流程。本书的研究充分，不足之处是有些案例讲述过于冗长。

WRAP决策流程

陷阱#1：思维狭隘——拓宽选择空间（ widen your options )

思维狭隘是指，我们倾向于将选择限制在极小的范围中，以二元化的简易思维看待选择。我们会问“我是否应该结束这段爱情”，而非“怎样才可以改善我们的关系”。我们会问自己“要不要买辆新车”，而不是“我想要花钱让我的家人过得更好，那么最好的花钱方式是什么”。

  1. 分析机会成本：我们做这个选择时放弃了什么？利用同样的时间和金钱，我们还可以做其他什么事情？

  2. 消失选项测试：你不能选择任何一个当前正考虑的选项，你还能做些什么？

  3. 同时找多个选项

    一项研究：一组设计师一次设计1个广告，修改5次；另一组设计师同时设计3个广告，修改3次。大家都设计了6个广告，结果是：同时进行多个设计的设计师们做出的广告得到较高评价，并且在实际测试中，这些设计获得更高的点击率。

    而且同时设计多个广告的设计师对反馈的态度不同：同时设计几项广告的设计师中有80%以上都认为反馈是有帮助的。在采取“一次设计一个”方案的设计师中，只有35%的人承认反馈是有用的，并且实际上，他们中一半以上的人认为收到的反馈信息是批评他们的。（但那些同时设计几项广告的设计师中，没有一个人认为自己受到了批评。）

    为什么这次经历对“一次设计一个”的设计师们来说如此挫败？调查者们猜测，这是因为人们在单向工作时，让自己的工作过于个人化了，因此把他人的评论看成是“对自己唯一选择的非难”。或者像调查者斯科特·克莱默所说：“如果我只有一个设计，那么我的自我意识就会和这个设计完美结合。但是如果我有很多个设计，我就能把自己与它们分开”。

    多目标追踪使我们时刻保持自省。如果你的老板有三个计划想要实施，那么她有可能愿意接受关于它们的各种各样的反馈。但如果仅有一个计划，那么她就会很难听进去真话，因为她的自我已经和那个计划合二为一了。

  4. 咨询解决过同样问题的人

陷阱#2：证实倾向——把假设放到现实中检验（reality-test your assumptions）

  1. 有意寻找不同意见

    如果最不讨我们喜爱的选择实际上却是最好的那一个，情况会怎么样？又是什么样的信息让我们对此信服？

  2. 学会提问：寻找具体的事实性信息

  3. 多参考外部意见，调查基本比率

  4. 多亲身尝试：探索现实而非预测现实

    尝试应该被当成一种加快搜集可靠信息的方法，而不是一种减缓我们做出值得全心投入的决策的方法。

陷阱#3：短期情绪—— 做出决策前，留出思考的距离 (attain distance before deciding)

  1. 10-10-10法则：10分钟、10个月、10年后，我会如何看待此刻的选择

  2. 小心曝光效应和损失厌恶，要留出距离

    曝光效应：人们会对自己更熟悉的东西产生偏好。

    损失厌恶：损失给人带来的痛苦似乎是收益带来的愉悦感的2~4倍。

  3. 为朋友提建议更好

    在帮助我们打破决策僵局时，最有效的提问可能会：如果面临这种情况的是我最好的朋友，那我会告诉他/她如何去做？

  4. 确定核心重点，将其视为行动纲领

陷阱#4：过度自信—— 做好出错的准备 (prepare to be wrong)

  1. 区间评估：思考可怕的前景会是什么，美好的前景会是什么，即最好和最坏的情况会是什么。

  2. 事前析误：假设决策失败，造成失败的原因可能是什么？

  3. 事前预演：针对未来可能的种种结局，要提前做好应对措施。

  4. 安全系数：提前控制无法预测的结果。

    假定正处于一种过度自信的状态，然后给自己一个适度的误差范围。

  5. 设置止损点：出现预警信号时，重新思考选择，并做出改变。
